# StickLab v0.5.9 — Carrying grips and safer releases

This update makes the Help grasp useful for short local transport and gives the grip a clear physical limit.

## Improvements

- **Walk while holding:** choosing 📍 Walk keeps the resident's current Help grip, releases other outside ropes or hinges, and sends the articulated figure toward the selected horizontal destination with the object attached. The grip remains at the destination while the resident rests.
- **Load-limited grips:** ball springs and box hinges can break under strong pulls. A resident reports the dropped grip, waits briefly before trying another grasp, and continues to follow its current behavior.
- **Object damage:** if a held box breaks apart, the grasp is removed and the resident receives the same drop feedback.
- **Clear status:** resident feedback distinguishes holding, sharing, and carrying. Walk hints mention when an object is traveling with the figure.
- **Player controlled release:** select a resident holding an object and choose **↘ Drop held object**. The resident confirms the drop and avoids immediately re-grabbing that same nearby object; it can try again after moving away or when Help is reapplied. This choice is retained in v4 scene saves.
- **Persistent scenes:** v4 scene validation accepts a grip during Help, a Walk command, and the resting state after reaching a destination.

Ball and small-box limits, the two-resident shared hold, collision response, and the existing local obstacle checks remain in effect. Carrying still uses a one-dimensional destination and the same local movement rules; it does not plan around complex routes, climb, lift heavy objects, or assign different jobs to cooperating figures.
