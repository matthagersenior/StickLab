# StickLab v0.5.0 — Choose Your Game

StickLab now offers **five clear game types**. The prior app only exposed three puzzle levels and a few quick world presets; those weren't a proper game-mode chooser.

## How to choose

Tap **🎮 Games** in the top toolbar on any supported screen orientation. The tools drawer opens at **Choose Your Game** with large, labeled options:

| Game type | What you play |
| --- | --- |
| **Free Sandbox** | Build, experiment, create and alter your own persistent scene. No goals. |
| **Physics Puzzles** | Choose from the existing three unlockable physics levels. Move the blue target ball into the green goal and let it settle. |
| **Engineering Lab** | Start beside a motor cart, hinged wheels, platforms and spare parts; construct and test machines with all sandbox tools. |
| **Ragdoll Chaos** | Start with multiple articulated figures, falling balls and structures for destruction and impact experiments. |
| **Living World** | Start in a populated scene with named autonomous figures, obstacles, loose objects and an unpowered wheel; take over residents and alter their behaviors. |

These five choices are all local to the existing HTML5 Canvas physics engine. The four creative modes have no scripted completion objective; **only Physics Puzzles has win conditions**. More gameplay systems can be added independently in future releases.

Selecting Physics Puzzles opens the existing level list, but does not start a level until the player chooses it. Opening the Games selector also makes no change to the world.

## Safeguards and compatibility

- The first time you enter a non-sandbox mode, StickLab preserves your Free Sandbox scene, camera, and pause state **in memory**. Selecting Free Sandbox restores them, even if you visited several modes and a puzzle in between.
- Saves and JSON exports still use scene format v4. Older scenes remain loadable.
- Selecting a quick world (Playground, Tower or Chaos) intentionally creates a new Free Sandbox world. Use Save or Export for persistent scene backups. Switching modes does not automatically persist its in-progress construction through browser reload.
- The existing build/physics tools, original challenge progression and AI toggle remain available.
- Android portrait/landscape uses the same top 🎮 Games shortcut with touch-size drawer options.
- The PWA cache was bumped so installed browsers can refresh to the new mode picker while staying offline-capable.

## Validation

Unit tests exercise each game type's actual scene contents, the optional puzzle-picker state, invalid mode protection, and restoration of a custom Free Sandbox. Chrome touch tests switch between all five modes while rotating the viewport, run a puzzle and return to the original scene. Existing responsive-layout geometry and offline single-file tests remain in CI.

This change does **not** claim additional mission objectives for Engineering, Chaos or Living World; those currently provide differentiated open-ended play.
