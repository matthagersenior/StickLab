# StickLab v0.4.4 — Optional levels with clear goals

Physics Challenges are opt-in. The default **Free Sandbox** has no win condition, timers, or required tasks.

## Discovery and play

- A visible **🎯 Levels** button opens the level list without leaving or deleting the Free Sandbox. Unlocked levels are selectable; locked levels remain disabled until earned.
- Each active challenge has a persistent objective: **move the blue target ball fully inside the green goal and let it settle**. The current level number, objective, and status are shown in the in-world goal panel, world subtitle, and challenge menu.
- Short landscape screens hide the large goal panel to make room for controls, but keep a compact objective in the title/subtitle; portrait screens with sufficient height show the mission panel.
- Completing a level visibly marks it solved and unlocks the next one. **Hints**, **Restart**, **Next level**, and **Return to Free Sandbox** remain in the challenge menu.
- Going back restores the sandbox objects and inhabitants, original camera position and zoom, and previous pause state. It does not wipe the creation. This restoration is held in memory during the current session; export a JSON scene for long-term safekeeping.
- Choosing Levels only opens the options. It does not start a level until a user selects one. Completing levels is entirely optional.

## Layout and safety

The mobile action bar displays **Menu / 🎯 Levels / Step / Play-Pause**. Photo export remains available in the menu, while desktop retains its photo button. The level instruction is noninteractive and does not cover camera or movement buttons in narrow or short screen orientations. A new service worker cache version makes updated controls discoverable for installed apps.

## Testing

Node regression coverage verifies opt-in transitions and sandbox restoration. Browser automation checks the button appears on Android-sized portrait without a menu, opens level selection without destroying the scene, shows a goal when chosen, and restores the world after rotating to landscape. The existing twelve-viewport control overlap tests continue to run.

## Limitations

The three starter puzzles remain open-ended physics scenarios. Automatic hints beyond the existing per-level guidance, persistence of an *in-progress* level across reloads, and a longer campaign are not part of this update.
