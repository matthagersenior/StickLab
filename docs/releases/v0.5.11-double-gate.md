# StickLab v0.5.11 — Double Gate challenge

The optional physics campaign now has a fourth level. **Double Gate** places two fixed barriers between the blue target ball and the green goal. Players can try any physical build; the game does not prescribe a solution.

The challenge picker and sidebar both show the new locked level, unlock progression follows the campaign length, and existing device unlocks remain compatible. The offline cache version advances with this release.

This level adds another construction puzzle, not a route planner. StickLab still uses local obstacle-aware movement and does not support full pathfinding or climbing.
