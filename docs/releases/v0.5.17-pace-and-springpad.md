# v0.5.17 — Pace, jump boost and spring pads

Figure controls now include direct movement upgrades:

- **Walk / Run / Sprint** cycles the selected or next controlled figure through three grounded movement speeds. The increased drive stays inside a bounded impulse, and the figure still moves through normal ragdoll joints, gravity and collisions.
- **Jump: Normal / Boost** toggles a stronger grounded jump impulse. It keeps the existing grounded check and jump cooldown; it does not create mid-air flight.
- **Spring Pad** places a bright, fixed rubber platform. Figures and loose bodies that land on it rebound with increased restitution. The pad is a solid physical platform, can be moved only by editing the scene, and is preserved in saved/imported worlds.

Older worlds continue to load with Walk, normal jump and no spring pads. Spring strength and resident movement settings are validated when worlds are imported.
