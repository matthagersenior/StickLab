# StickLab v0.5.1 — Physics Puzzle Level Picker

**Reported issue:** On Android, choosing **Physics Puzzles** inside the Games menu did not visibly proceed to a level. The original code attempted to scroll the large sidebar to the "Optional Physics Challenges" heading. On a deeply scrolled mobile sidebar this looked like nothing happened, leaving the player staring at World Management controls.

## Fix

- Choosing **Physics Puzzles** now opens a dedicated, clearly titled **Choose a physics level** dialog, independent of menu scroll position and orientation.
- Level 1 **First Push** is a visible, enabled button. Levels 2 and 3 explain that they are locked until earlier levels are completed.
- The dialog includes the objective: get the blue ball into the green goal using your physics tools.
- Tapping an unlocked level starts it immediately, closes the chooser, and closes the sidebar so the playfield is visible.
- Closing the dialog or tapping **Back to Games** does not start a level or delete the scene.
- Existing level progression, world saves, undo, construction tools, resident AI, touch controls, and free sandbox restoration remain unchanged.
- The installable web app cache is incremented for the new UI; refreshing while online downloads the corrected layout.

## Validation

Automated real-browser testing reproduces a sidebar scrolled down to World Management, then chooses Physics Puzzles and confirms the level chooser appears in view. It checks locked-level states, the Start button in the viewport, the actual transition to Level 1, and the goal instructions. Existing responsive tests exercise portrait, landscape, and the rest of the game modes.

Physical-device support still depends on the Android browser and its accessibility/display scaling settings. The reported device is the next meaningful manual confirmation.
