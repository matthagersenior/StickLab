# StickLab v0.5.10 — Mobile clarity and team carrying

This update makes challenge startup clearer on phones and lets residents that share an object travel as a team.

## Improvements

- **Clean challenge start:** loading a level clears old selection, held movement keys, drag state, and the previous tool; it starts in Grab mode with the challenge running.
- **Pause guidance:** when a challenge is paused, its instruction card now says that physics tests require pressing **▶ Play**.
- **Less control overlap:** movement arrows are hidden until a figure is selected or a resident is walking, keeping them off empty challenge screens.
- **Shared carry:** Help residents are more willing to join a nearby resident's existing grip. Sending either holder with **📍 Walk** gives all holders of that object the same destination; each retains the physical connection.

Movement still follows the existing local obstacle checks. Shared carrying does not provide global route planning, climbing, or recovery from every obstacle.
