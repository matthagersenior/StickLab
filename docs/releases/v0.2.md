# StickLab v0.2 release — 2026-10-26

## Included

- Unified construction and ragdoll simulation kept from v0.1.
- Collision candidate spatial grid, deduplicated pairs, rotated box bounds, and oriented box-to-box and box-to-circle collision checks.
- Angular Verlet motion for box bodies and attachable two-point hinge constraints.
- Hinge placement tool, one-frame step control, and touch tap-to-place with two-finger pan/zoom.
- Versioned export and validated import: rejects invalid versions, duplicate IDs, missing joint references, and non-finite values without changing the active scene.
- Three save slots with a v0.1 slot-1 fallback. Legacy exports remain importable.
- Deterministic build from source, offline distributable, and install metadata for GitHub Pages.
- CI test suite covering scene migration, collision candidate completeness, basic hinge behavior, touched scene placement, and build integrity.

## Notes

- Material fracture, breakable joints, motors, vehicles, and autonomous stick-figure AI remain v0.3/v0.4 scope.
- The collision and constraint solver is a stylized game simulation, not engineering-grade structural physics. Extreme stacks and dense ragdolls can exhibit jitter. Collision broad-phase worst-case remains quadratic when all bodies overlap.
- Browser local storage is not synchronized across devices. Export/import JSON for portability.
- Modern web-app installation support varies by device and browser; the self-contained offline HTML remains the compatibility baseline.
- Automated tests cover logic and simulated input. Performance targets and real-device frame rates still require testing on representative low-end phones and older desktop browsers.

GitHub Actions: `node --check src/core.js`, `node --check src/game.js`, `node scripts/build-offline.cjs`, `node --test tests/*.test.cjs`, and `git diff --exit-code -- index.html StickLab-Offline.html`.
