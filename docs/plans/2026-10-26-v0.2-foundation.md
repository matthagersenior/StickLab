# StickLab v0.2 Foundation Implementation Plan

> **For agentic workers:** Use the host's available task-by-task implementation workflow. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Evolve the working StickLab v0.1 prototype into a versioned, efficient single-world physics foundation without sacrificing offline play or legacy Canvas support.

**Architecture:** The existing dependency-free Canvas/Verlet-style prototype remains the baseline. Extract independent scene migration, broad-phase indexing, and construction constraints behind testable functions while keeping the browser-facing input/rendering logic compatible. Maintain a reproducible self-contained `index.html` for instant offline play and a modular `src/` authoring version.

**Tech Stack:** Plain JavaScript (legacy-compatible at runtime), HTML5 Canvas, CSS, Node.js for build/test tooling; no mandatory runtime dependencies.

## Global Constraints

- Preserve all three v0.1 preset worlds, touch/mouse/keyboard operation, ragdoll selection/control, ropes/springs, local saves, and JSON import/export.
- All player-facing features must run locally with no account, no network and no WebGL requirement.
- Older v0.1 exports (format `StickLab`, version `1`, `world.parts/links/groups`) must remain loadable.
- Build edits and simulation share one world; avoid destructive import or load until validation succeeds.
- Use bounded simulation work, cap impulses, and never delete saved objects merely to achieve FPS targets.
- Runtime code must not depend on Node, bundlers, ESM, remote CDNs, or service worker APIs.
- Named character AI and structural destruction are later v0.3/v0.4 milestones, not part of this v0.2 completion claim.
- GitHub Pages requires separate activation/verification; passing local checks does not imply a live public URL.

## Unresolved choices outside v0.2

- A public Pages URL is optional and requires a separately configured repository deployment source.
- Actual minimum supported old-device browser/OS versions must be established by physical testing; Canvas support alone is the compatibility promise.
- Future damage/AI detail follows the approved specification, but its tuning values must be measured and reviewed when those milestones are implemented.
