# StickLab

A lightweight, offline-first, cross-device stick-figure physics sandbox.

**Playable prototype:** open `index.html` in a Canvas-capable browser. The project uses no build system, runtime library, account, or network request. On older machines, select **Eco** quality. Saved scenes stay on your device; you can also export and import JSON scenes.

### The game

- Build using stick figures, blocks, balls, fixed anchors, ropes, and springs.
- Grab and throw objects, alter gravity and bounce, pause, and experiment.
- Control stick figures with keyboard or touch, or leave them as physics ragdolls.
- Switch among Playground, Tower, and Chaos scenes.
- Save, load, import, and export experiments.

### Development

See `docs/specs/2026-10-26-living-sandbox-design.md` for the approved unified physics/construction/destruction/AI design. The prototype is **v0.1**. Rotating objects, hinges, damage simulation, and autonomous agents are roadmap features, **not yet implemented**.

**Platform target:** HTML5 Canvas, plain JavaScript, touch + mouse + keyboard, with PWA installation optional on HTTPS hosting. GitHub Pages hosting is not automatically enabled by uploading a file.
